# Currency-Converter
A responsive Currency Converter built with HTML, CSS, and JavaScript that fetches real-time exchange rates, supports 25+ currencies (including PKR), features instant conversion, currency swapping, and a modern glassmorphism UI.
## ✨ Features
- 🌍 Real-time exchange rates
- 💱 Supports 25+ currencies
- 🇵🇰 Includes Pakistani Rupee (PKR)
- 🔄 One-click currency swap
- 📱 Fully responsive design
- 🎨 Modern glassmorphism interface
- ⚡ Instant conversion as you type
- 🔄 Automatic rate refresh

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- ExchangeRate API
- Font Awesome Icons
